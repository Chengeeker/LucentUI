# 页面模板

主界面按 Review 的时间线结构组织：头像入口、18sp标题、编辑/搜索动作；动态卡片使用22dp圆角和原有密度；三项目底栏保持 Review 几何。第二页为组件目录，第三页为 Review 结构的设置首页。业务名称与示例图像允许替换。

阅读评论页使用本地内容，评论行沿用 Review 的48dp头像点击区、36dp头像、10dp列间距、13.5sp作者、11.5sp时间、14sp正文和8dp嵌套回复底色；评论全部参与顶栏背景采样。草稿、收藏、过滤、加载更多与本地回复可运行。业务徽章、认证标记、远端评论及平台富文本不是此Demo的复制目标。

目录另含音乐/歌词、剧集、设备传输、插件键盘、搜索消息等功能示例：这些不是 Review 本来具有的界面，不应拿来定义其基础规范。音乐和视频播放是真实本地媒体；设备、插件与会话场景使用明确的本地样例，接入生产时替换业务模型。

保持页面的实际操作对象清楚。真实网络功能与本地演示状态不能用同一句“成功”混淆。规范主入口是设置中的“关于与规范”，可离线阅读各章节。


## 动态更多菜单（0.2.1）

点击“更多”只打开对应动态的底部菜单，显示作者及动态序号；退出菜单没有数据副作用。收藏/取消收藏仅操作该动态，重启后仍保存，不能覆盖其他动态或文章的收藏。复制正文写入系统剪贴板；分享与转发打开系统分享选择器，未选择目标不会发送内容。没有实现的删除/举报操作不展示成功假反馈。条目样式使用现有LucentRow和Review触感。
