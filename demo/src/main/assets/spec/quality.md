# 验收与历史回归

当前结果单独记录于verification.json；未跑的场景必须标为未验证，不能继承0.1.0结论。

1. 与同一模拟器上的Review正式包对照默认设置、个性化、WebDAV布局；检查相同密度、字号、系统模式和动态色。
2. 检查暗色/动态取色的设置卡片轮廓；100%字体不重复缩放。
3. 滚动正文和评论穿过顶栏，采样应一致；玻璃overlay不进入自身来源层。
4. 图库进入/返回、快速重开、缩略图联动、双击缩放、长图、GIF及系统返回；退出不留黑屏或被隐藏原图。
5. 视频实际播放、暂停、换源和倍速；单源无画质按钮；页面非活动及App后台暂停，离开释放。
6. 安全备份排除凭据；全量加密正确密码可解密，错误/损坏/超限不覆盖数据；目录名称与HTTPS边界检查。
7. 设置持久化、图标别名、系统授权、取消和错误反馈；ARM64、包名、版本、签名及16KiB对齐检查。

既有错误：0.1.0独立设计偏离实际应用，禁止再次以“统一设计”替换Review真实布局；禁止只比较代码或编译成功便宣称视觉一致。旧导航透明度规则已撤销。Review源码只读，原应用零修改。

实体GPU、低版本真机、HDR、手势触感、个人服务器与账号仍需现场验证。不要保证所有设备绝不崩溃。
