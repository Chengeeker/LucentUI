# 交互、手势与动画

动效解释对象的来源、去向和状态。默认启用，尊重系统动画比例和 Demo 的减少动画开关。

| 场景 | 默认契约 |
|---|---|
| 页面切换 | 300 ms 小幅水平位移 + 220 ms 进入淡化；120 ms 退出 |
| 导航选中透镜 | glassSpring(350 ms, bounce=0.15) |
| 长按拖动透镜 | 150 ms、bounce=0.15；释放 240 ms 回弹 |
| 图库打开/关闭 | 350/240 ms；有来源位置时从来源中心和宽度过渡 |
| 按压形变 | 轻微横向压缩、纵向延伸；不推动周围布局 |
| 加载进度 | 只在实际任务或明确标记的模拟任务中变化 |

弹簧换算：dampingRatio=1-bounce（正 bounce）；stiffness=4π²/(durationSeconds²)。减少动画时使用 snap 或零时长，保留最终状态与操作结果。

## 手势归属

- 普通点击无水波纹，但保留必要触感。只由最终接受手势的控件发送一次。
- 导航：短按切换；长按后横向拖动选中透镜；取消不提交新目标。
- 图片：双击缩放，双指缩放/平移；放大后单指平移；原始倍率下横向翻页、纵向退出。
- 图片缩放处理器不吞掉原始倍率下的单指翻页。返回和快速重开使用独立状态，关闭回调只能发生一次。
- 视频：双击播放/暂停；水平拖动预览并在松手定位；左侧调亮度，右侧调音量；长按临时 2×，松手或取消恢复原速度。
- 编辑器与底部面板：输入法出现后确认按钮仍可滚动到；关闭时保存草稿的行为必须明确。

物理触感强度、长按误触率和设备帧率需真机验收，宿主测试或模拟器不能代替手感评价。

阅读页支持实际下拉刷新反馈与分页。刷新协程随页面销毁而取消，避免旧页面任务回写新页面。程序化筛选/排序更新应直接刷新列表，只有手动下拉才显示下拉动效。
