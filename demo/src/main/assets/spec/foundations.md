# 基础与设计变量

基准代码：`review/ReviewTheme.kt`、`Palettes.kt`、`FontWeight.kt`、`SettingsCardColor.kt`。

## 主题

直接使用 Review 的八套明暗静态调色板，不再用同色种子重新生成近似配色。默认经典红、跟随系统明暗；动态取色关闭，字号100%，字重跟随系统，悬浮底栏开启，液态玻璃关闭，触感开启。
动态取色沿用 Review 的平台取色及 surface 修正。纯黑模式只在深色下生效。卡片使用 `surfaceContainerHigh`；若其与页面亮度比例低于1.12，则以10% `onSurface` 叠加页面实色，保持轮廓可辨。

## 排版

系统 fontScale 与应用字号只组合一次。应用范围85%–150%，步长5%；100%不额外乘95%。字重开关独立于字号，关闭时尊重系统；开启后按 Review 的字体解析器调整，范围−300至300，步长100。

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 子页顶栏 | 18sp | Bold |
| 设置首页主行 | 15sp / 20.25sp | Review 默认 |
| 设置首页副文 | 12.5sp / 17.5sp | Review 默认 |
| 个性化开关标题 | 16sp | SemiBold |
| 个性化开关说明 | 14sp / 19.6sp | 常规 |
| 时间线正文 | 16sp / 24sp | 常规 |
| 评论正文 | 14sp / 19.6sp | 常规 |
| 图库页码 | 13sp / 16sp | Bold |

设置首页组标题跟随 `onSurfaceVariant`；个性化分组标题跟随 `primary`。这是 Review 的不同页面层级，不能在同一层级随意混用。

## 几何

页面左右16dp；设置卡24dp圆角；子页顶栏56dp；设置行最小56dp，有副文时72dp；触摸目标至少48dp。时间线卡左右8dp、上下4dp、圆角22dp、内容14dp。默认悬浮底栏高56dp，宽 `min(440dp, screenWidth−40dp) × 2/3`。
