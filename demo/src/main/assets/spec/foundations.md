# 基础与设计变量

Lucent UI 从已确认的共用规则抽取。`lucent-ui/Theme.kt` 是运行时来源；`tokens.json` 是跨工具交换文件。界面可在 Demo → 组件与交互、设置 → 个性化直接验证。

## 三层变量

| 层级 | 示例 | 使用方式 |
|---|---|---|
| 原始值 | 4、8、12、16、24、32 dp；150、240、350 ms | 定义刻度，不直接表达业务意义 |
| 语义值 | background、onSurface、primary、surfaceContainerHigh | 由明暗模式、种子色或系统动态配色产生 |
| 组件值 | pageInset=16、cardRadius=24、controlTarget=48、headerHeight=64 | 对外 API 默认采用这些变量 |

## 排版与缩放

- 默认字号显示和实际倍率均为 100%。应用倍率乘系统 fontScale **一次**，不把 95% 重命名为 100%。
- 设置范围 85%–150%，5% 一档。Slider 有 12 个内部刻度；拖动只预览，松手持久化。
- 七档字重为基础字重 ±0/100/200/300，限制在 100–900；重置恢复跟随系统。
- 静态配色使用 HCT/TonalPalette 产生八种种子色的语义色阶；采用 Material 3 的 title/body/label 角色，不因某个页面而全局修改 Density。
- 设置行标题 bodyLarge、半粗；说明 bodyMedium、onSurfaceVariant。分组标题统一 primary。
- 长文字优先换行、增加行高；不通过缩小文字挤进固定高度。数字页码是图库选定的 13 sp 粗体特例。

## 色彩与表面

- 跟随系统、浅色、深色；深色可选纯黑页底。系统动态配色需 Android 12+，低版本采用静态种子配色。
- 分组卡片优先 surfaceContainerHigh。与**实际页底**对比不足 1.12 时，用 10% onSurface 叠加页底得到不透明颜色。
- 1.12 是分组辨识阈值，不能代替无障碍对比度：普通正文至少 4.5:1，重要图标/控件边界至少 3:1。
- 图像上方媒体控件采用暗色保护层与白色前景。不可只依赖主题色或颜色变化表示状态。

## 布局

页边 16 dp；卡片圆角 24 dp；行内边距 16 dp；图标 24 dp；图标与标题间距 16 dp。无说明行最小 56 dp，有说明最小 72 dp。交互目标至少 48 dp。

页面背景可延伸到系统栏；交互区域消费一次系统安全区。编辑器和表单使用 IME padding。横屏视频独占视口；普通长页面保持可滚动。大屏布局需要给内容设置合理最大宽度，避免把手机行无限拉伸。

## 禁止回归

“跟随系统”不添加重复小字说明；分组标题不混用主色和普通文字色；动态配色不能让卡片消失；不能在每个窗口重复叠加字号。
