# 通用设置与备份

## 个性化

顺序与 Review 一致：明暗模式、色彩方案、字体粗细、字体大小、底部导航、显示效果、应用图标、屏幕帧率、触感。跟随系统选项没有小字说明。默认值与字体解析见基础规范。改动立即作用于当前App并原子持久化。
应用图标有三种本项目资源，选择会启用对应Launcher别名再禁用旧别名，避免短暂没有启动入口；刷新时机取决于桌面。帧率设置向系统提交期望帧率，系统保留最终决定。

## WebDAV

参考 Review BackupScreen：顶部说明容器圆角16dp、内边距14dp；安全/全量选择卡圆角24dp；间距16dp；服务器配置卡内边距16dp，字段间12dp；最后为并排上传/下载按钮。
Demo保留独立密码加密全量备份，这是有意保留的安全协议差异。默认安全备份排除账号、WebDAV账号/地址/密码以及设备目录授权；加密全量包含演示账号与连接密码，用独立8–256字符密码加密，换机在新Keystore重新封装。密码不写入日志或普通偏好。
服务器必须HTTPS，拒绝URL内嵌账号、查询和片段。文件夹只允许单段名称，拒绝路径穿越；空值保持原0.1.0完整目录URL行为。测试和上传会检查目录，缺失时请求MKCOL；不自动跟随认证跳转。上传只接受200/201/204，下载只接受200并验证大小、格式和密码。备份文件固定为 `lucent-ui-backup.json`。
表单提交会保存当前连接设置；恢复文件只有校验及重新加密成功才原子替换内容。失败保留原草稿、收藏和会话；读取旧密文失败不当成空密码覆盖。上传和恢复有明确覆盖确认，取消提示不把未知远端状态说成失败或成功。

## 其他功能

本地导入导出用系统文件选择器；存储目录使用持久授权，换机必须重新授权；缓存清理只在本App缓存边界内；通知调用真实系统授权及本地通知；网络诊断使用配置的HTTPS和代理；隐私页可设置截图保护；演示账号、草稿和收藏均本地保存。
账号页明确展示演示会话，不伪装成真实平台登录。设备、插件、键盘、音乐等扩展保留在目录中，能力边界见页面规范。
