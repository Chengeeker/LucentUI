# 通用设置功能

本页列出可复用功能契约。`demo/data/DemoData.kt` 管理 Demo 自身数据；其他应用接入时保留各自账户、后端和数据库。

| 页面 | 实际行为 | 边界 |
|---|---|---|
| 个性化 | 模式、纯黑、动态配色、字号字重、玻璃、动画、触感、刷新率请求持久化 | 刷新率由系统/硬件决定 |
| 阅读与内容 | 密度、头像、时间、回复预览、屏蔽词、收藏、历史 | 只影响 Demo 阅读场景 |
| 图片与视频 | 默认画质、速度、自动播放、循环、低流量默认源 | 在线带宽策略由业务实现 |
| 存储与下载 | 系统授权目录、默认目录、实际保存离线视频、取消、清缓存 | 不删除其他应用或用户目录 |
| WebDAV | 保存连接、PROPFIND、PUT、GET、确认与结果 | 用户自行配置 HTTPS 目录 |
| 本地备份 | 系统文件导入/导出、校验、确认覆盖 | 限定 Lucent schema，不导入其他应用私有备份 |
| 通知 | 运行时权限、系统设置、本机通知预览 | 无平台推送、无永久后台轮询 |
| 网络 | 超时和 HTTPS HEAD 诊断 | 连通不代表账户有效 |
| 隐私 | 安全窗口、浏览记录清理、重置 | 只处理本应用数据 |
| 账号 | 本地模拟登录、检查、退出 | 明确标记，不登录真实平台 |
| 关于 | 内置离线规范、版本和许可 | 与仓库 docs 同步打包 |

## WebDAV 与迁移

安全备份默认选中，排除账号、WebDAV 地址/用户名/密码和旧设备目录授权。全量备份包含可迁移的连接资料，用独立备份密码加密，8–256 字符；PBKDF2-HMAC-SHA256、210000 次、随机 16 字节盐；AES-256-GCM、随机 12 字节 nonce、认证格式标识。

本机授权密码使用 Android Keystore AES-GCM 保护，不把设备绑定密文直接当作跨设备备份。全量导出先解开本机保护，再用备份密码加密；恢复后用新设备密钥重新保护。

URL 必须 HTTPS，不允许内嵌账号、查询或片段。写请求不跟随重定向；下载最多五次跳转，跨源清除 Authorization、Cookie 和认证器，不允许 HTTPS 降级。下载和文件导入上限 1 MiB。

恢复在写入前校验格式、版本、类型和数值范围；所有设置与凭据一次 AtomicFile 替换。非法文件、错误密码或网络失败保留现有数据。旧设备 SAF 权限不能迁移，恢复后重新选择目录。

上传使用目录内固定文件 `lucent-ui-backup.json`，覆盖前确认。以服务器成功状态为准；取消后提示可能已经写入，要求核对而非声称未发生。

## 接入其他应用

提取共同表单与结果界面，应用提供 schema、序列化、秘密字段清单、提交事务和账号有效性检查。禁止通用 Demo 将“能解密”误判为“远端仍然登录有效”。不自动清空无法读取的旧凭据。

账号、播放源、后台签到、通知订阅、下载引擎、输入法插件等平台策略通过接口接入；这些后端不能因 UI 看起来相同而合并。

兼容实现：缺少 PBKDF2WithHmacSHA256 提供程序的旧系统采用 HMAC-SHA256 等价派生，使用标准测试向量及 Unicode 密码交叉验证。系统云备份与设备搬家均排除设备绑定数据，统一走显式备份流程。参考 [Android SecretKeyFactory](https://developer.android.com/reference/javax/crypto/SecretKeyFactory) 与 [Auto Backup](https://developer.android.com/identity/data/autobackup)。
