# LucentUI 设置交互规范

## 类型约定

1. 布尔开关：使用 LucentToggle / Material 3 Switch，直接切换，始终展示当前状态。
2. 离散单选：使用 LucentChoiceRow 弹窗或 LucentOptionRow 子页面。点击条目只打开选择界面，不得隐式轮换下一个枚举或数值。
3. 连续数值：使用有数值说明的 Slider，必要时提供步进和重置，不得以反复点按代替调整。
4. 导航/操作：使用 LucentRow / LucentAction，危险操作需要二次确认。
5. 多选：单独的多选组件，明确候选项的勾选状态，不得伪装成单选。

## 单选约定

- LucentChoiceRow：设置首页显示当前选项的可读标签，点击后打开完整候选列表。
- LucentOptionRow：弹窗或子页面的候选选项统一显示单选标记，整行可点，支持无障碍。
- 仅点选具体候选项时调用 onSelect 并关闭弹窗；点击取消或外部不提交设置。
- 原有设置的持久化和旧备份导入继续兼容，未识别值应保留或提示重新选择。
- 触觉反馈使用 LucentUI 全局设置，动画遵循系统及应用动效开关。

## WebAlbum 本轮迁移

- 播放进度条样式：直线（默认）和波浪线
- 歌词字体大小：16、18、20、24、28、32、36、40 sp
- 歌词文字粗细：100 至 900（每档 100）
- 图库/文件夹列数、帧率、缓存阈值、网络超时、连接方式：复用统一 LucentOptionRow，但保留原本合规的选择页或选择弹窗
- 原有图标、外观模式与配色等已可明确选择的界面不改动；布尔值继续使用开关

## 迷你播放器下滑收起

- 左右滑动仍为切换歌曲；下滑独立识别，不影响短按播放按钮。
- 下滑有效阈值约 56dp，纵向距离需超过横向距离的 1.2 倍。
- 收起只隐藏界面，不停止后台 MediaSession；相册网格不再预留迷你播放器的额外空白。
- 相册顶部出现“重新打开音乐播放器”入口，可随时恢复全屏播放界面。
- 尊重全局震动与动效设置。

## 进度条视觉

- M3 波浪样式：已播放部分仅波浪，未播放部分仅直线，彼此分段，禁止在已播放区下面叠加直线。
- 波浪模式竖向滑块高度为 22dp；直线模式保留原 M3 默认尺寸。
- 保留 Slider 本身的拖动、进度跳播和无障碍交互。


## 2026-11-17 图标和文字层级统一

- 音乐播放设置的所有条目统一采用左侧 Material 图标、标题、辅助说明及右侧控件。
- 切换型设置仍用 Switch；离散选项打开明确选择弹窗，不将开关改成选择框，也不让单选行点按后循环。
- LucentToggle 增加可选 icon 参数并与 LucentRow 共享标题 15sp / 辅助文字 12.5sp 的字级，消除同一分组内标题粗细及起点不同的问题。
- 「显示迷你播放器」放在最前方，再显示依赖其启用状态的「收起后重新显示」单选设置，减少逻辑跳转。
- 独立 LucentUI 的同名组件同步了可选图标和文字层级，未覆盖其他未提交文件。

## 2026-11-17 底部播放器与悬浮栏

- 多选操作栏应始终贴底部（遵循导航栏安全区）；先抬升迷你播放器，再从屏幕底部显现操作栏。
- 有系统导航栏时迷你播放器上抬 64dp，无导航栏时上抬 72dp，按 ReviewBottomBar 内边距推算，保持约 8dp 的胶囊视觉间距。
- 两种组件的进入和退出采用不同的轻微时序，允许用户中途切换。
- 恢复已收起的迷你播放器时从下方进入；从全屏收起时保留共享元素动画。


## 2026-11-17 布尔与单选顺序、迷你播放器精简

- 同一个设置分组中，应先排列所有布尔 Switch 项，再排列所有离散单选 Choice 项；信息/导航行放在分组末尾。保留左侧统一图标、标题/说明字级及右侧控件对齐。
- 音乐设置的「播放与交互」「歌词界面」已按 Switch → Choice 顺序排列；不改变存储或备份设置语义。
- 迷你播放器已移除直线/波浪进度轨道，缩短为仅显示封面、标题、歌词摘要和播放操作的单行；进度条样式仍只用于全屏播放器。
- 多选浮动底栏固定在底部**只做快速淡入淡出**；迷你音乐卡片在其上方先抬升、退出时等待底栏消失后下降，两者保持较小视觉间距。
