# 手势与动画

`review/PageStack.kt` 保留 Review 页面栈：进入320ms、退出220ms，退出页绘制在进入页上方，手势返回按进度更新；只有仍为栈顶的同一路由能完成出栈。非活动页降到CREATED生命周期，防止播放器留在后台运行。

普通底栏选中面240ms，标签颜色及字重150ms。玻璃导航保留原有拖拽、取消及速度响应，不用普通按钮缩放替代水珠效果。

图库复用 `GalleryFlight.kt`：从源图屏幕坐标和当前位图出发，进入和退出均保留裁剪圆角；飞行期间原图隐藏，结束或销毁时恢复。返回途中重新点击可重新打开；关闭回调带代次保护，避免旧任务关闭新页面。
双击缩放220ms；普通图片1→2.5→6→1，长图1→3.5→6→1；双指最高8倍。原始倍率下垂直拖动超过高度18%退出，未达到则200ms回弹。

使用系统动画时长比例。单次操作只发一次触感；长按、拖动选择及完成反馈沿用 Review。静态单元测试不代表真实手指触感验收。


## 入口验收补充（0.2.1）

图库进入330ms、返回200ms，使用原Review运动曲线；不是320/220ms普通页面切换。依赖实际点击来源的GalleryOrigin，不得仅复用GalleryFlight却漏接页面入口。图库Host必须放在PageStack/BackdropHost外侧，原页面保持挂载，退出后保留滚动位置。

验收按“时间线图片→返回→立即点同一原位”和“文章正文图片→返回”进行；同时检查点击第2/3张进入正确索引、横滑切换后返回、长图和GIF首帧。检查中间帧的图片位置与裁剪，不能仅断言最终图库可见。诊断时临时使用系统5倍动画时长捕捉中间帧，结束恢复原配置；另保留默认速度录屏。

## 可预测性返回（0.2.3）

个性化 → 手势与动效 → 可预测性返回默认为关闭。Android 14 及以上在系统提供进度且动画启用时，开启后应用内普通页面随手势移动，完成后返回上页，取消恢复原位置。关闭时仍可使用返回手势及返回键，提交时按普通返回处理。图库、全屏播放器和弹层优先处理自己的退出。
