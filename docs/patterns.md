# 产品页面模板

| 模板 | 示例交互 | 来源边界 |
|---|---|---|
| 阅读与评论 | 正文/评论共同磨砂、收藏、回复编辑器、草稿、分页、过滤 | Review、GreenNote、RedNote、Lurk、论坛应用 |
| 搜索与消息 | 页面搜索、建议、未读变已读、本地会话 | 通用搜索/通知模式 |
| 音乐 | 封面、播放控制、队列、歌词、收起/展开 | GreenMusic、RedMusic；后端与会话保留各自实现 |
| 剧集 | 竖屏播放器、喜欢、选集、下一集 | Review X、RealDrama 专用模式；不强行统一普通视频 |
| 设备与传输 | 在线/离线、连接/断开、进度/取消/完成 | Hinge；Demo 明确模拟，无网络扫描 |
| 插件与键盘 | 启停、配置、候选词、九宫格/全键盘预览 | Xime；Demo 不注册输入法、不运行插件 |

平台专有签到、远控协议、订阅解析、会员/音质权益、输入法候选算法属于业务实现。规范记录操作对象、状态与反馈，不伪造这些后端。

每个接入页须填写：数据来源、空态、加载态、错误/重试、可取消点、持久化时机、权限、返回行为。真实操作与模拟操作必须在界面上可区分。
