# 兼容性、性能与验收

## 必测矩阵

- 浅色、深色、纯黑、静态和动态配色；卡片层次与文字对比度分别检查。
- 系统与应用字号组合，至少应用 100%/150%；窄屏、横屏、键盘、系统手势与三键安全区。
- 顶栏滚动覆盖正文、图片、评论、回复；不显示清晰原字。
- 图库快速退出重开、滑动中返回、双指与单指手势切换、长图/动图。
- 视频两档/单档、速度、暂停切源、旋转、退出、后台暂停与错误重试。
- 安全/全量备份、本地/云端、错误密码、格式/版本/类型错误、超限、重定向认证隔离、取消和原子写入失败。
- 权限拒绝、目录失效、存储不足、通知关闭、无网络。

## 性能边界

背景使用 GPU GraphicsLayer；避免静止页面持续 CPU 读回。Shader 按组件记忆，不逐帧读取 assets。图片按可见页面加载；播放器离开页面必须释放；没有后端需要时不保活服务。备份 KDF、文件 I/O 和网络不占主线程。

发布前查看依赖一致性、资源收缩后的启动、签名、包名、版本、ABI、zipalign 和 SHA-256。宿主测试不能替代 APK 安装运行，模拟器不能替代真实设备触感、HDR 或不同 GPU 的表现。

具体已执行结果与仍未覆盖的项目记录在 `implementation-status.md`，未验证项不能写为通过。
